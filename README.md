# Tipplay — Sportsbook, Casino & Virtual Games Platform

**Tipplay** is a modern sports betting and casino web application engineered for high performance, mobile-first accessibility, and vibrant player experiences.

## Features
- **Sportsbook**: Pre-match & Live Betting feeds with tabular odds presentation.
- **Virtual Games**: 20 Virtual & Instant game formats with provider SDK integration scaffolding.
- **Crash Games**: Aviator-style real-time multiplier flight simulation.
- **Casino & Slots**: Pragmatic-style demo slots and Keno draw games.
- **Localization**: English and Amharic (አማርኛ) support.
- **Mobile-First UX**: Sticky bet slip, bottom navigation bar, video-driven hero carousel (`<HeroVideoCarousel />`), and live odds ticker.
- **Hero Video Handoff**: See `docs/HERO_VIDEOS.md` for video rendering, MP4/WebM compression (<2.5MB), and safe zone overlay guidelines.

## Tech Stack
- **Framework**: Next.js 16 (App Router), React 19, TypeScript
- **Styling**: Tailwind CSS v4, Framer Motion
- **Icons & Graphics**: Lucide React, Custom SVG geometric brand identity
- **State Management**: Zustand
- **Database & Auth**: Prisma ORM, NextAuth.js

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view Tipplay.
